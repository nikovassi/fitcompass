# FitCompass

Безплатна фитнес платформа на български: инструменти и ясна информация за тренировки, хранене и прогрес.

**Живият сайт:** https://nikovassi.github.io/fitcompass/

## Какво има

| Стълб | Страници |
|---|---|
| **Тренирай** | Тренировъчни програми · Упражнения · 1RM калкулатор |
| **Храни се** | Основи на храненето · Рецепти · **База данни с храни** · **Калориен калкулатор** |
| **Разбери** | Добавки · Витамини и минерали · **Инсулинов индекс** · Фитнес ръководства |
| **Следи** | Прогрес (тегло, история на тренировките, цели) |

Калкулатори: калориен (основен), BMI, BMR, TDEE, макроси, протеин, 1RM.
Светла и тъмна тема (следва системната настройка, с ръчен превключвател).

## Технологии

Статичен сайт без build стъпка — HTML, CSS и ES модули. Хоства се директно от клона `main` в GitHub Pages.
Няма външни JS библиотеки; диаграмите са собствени SVG компоненти.

```
index.html, *.html        страници
css/styles.css            дизайн система (светла/тъмна тема)
js/lib/calculations.js    ВСИЧКИ формули (BMR, TDEE, цели, макроси, 1RM, единици)
js/lib/validation.js      валидация на входните данни
js/lib/foodRules.js       филтри, етикети „Подходящо за“, търсене, сортиране
js/lib/progress.js        логика за прогреса и безопасно localStorage
js/pages/*.js             логика на отделните страници
data/foods.js             база данни с храни (USDA FoodData Central)
data/insulin-index.js     инсулинов индекс — само измерени стойности
data/sources.js           източници
tests/*.test.js           тестове (node:test)
```

## Тестове

```bash
npm test        # node --test, без зависимости
npm run serve   # локален сървър на http://localhost:8080
```

Тестовете покриват BMR, TDEE, калорийни цели, макроси, преобразуване на единици, валидация (празни, отрицателни,
невъзможни стойности), реалистични профили, цялост на данните (всеки инсулинов индекс има източник, няма измислени
стойности), търсене и филтри, прогрес и вътрешните връзки. GitHub Actions пуска тестовете при всеки push.

## Методология на калорийния калкулатор

* **BMR** — Mifflin-St Jeor (1990): `10·kg + 6,25·cm − 5·възраст + 5 (мъже) / −161 (жени)`.
* **TDEE** — компонентен модел вместо един множител:
  `(BMR + работа + крачки + тренировки) × 1,10 (TEF)`
  * работа (без ходене): 5–45% от BMR според типа;
  * крачки: `крачки × kg × 0,0005` kcal;
  * тренировки: нетни MET kcal `(MET − 1) × kg × часове` (Compendium of Physical Activities 2011), осреднени на ден;
  * бягане: `0,9 kcal × kg × km`.
* **Цел** — отслабване −20% (300–750 kcal, не под 1200/1500 kcal или BMR), мускулна маса +8% (150–350),
  качване +15% (300–600), постижения +5% (до 250).
* **Макроси** — белтък 1,6–2,0 г/kg (при BMI > 30 спрямо тегло при BMI 27), мазнини 25–30% (мин. 0,6 г/kg),
  въглехидрати — остатъкът.
* Очакваната промяна на теглото се показва като диапазон (±25% около модела 7700 kcal/kg).

## Източници на данни

* Хранителни стойности: USDA FoodData Central, SR Legacy (2018). Всяка храна пази `fdcId`.
* Гликемичен индекс: Atkinson, Foster-Powell, Brand-Miller. *Diabetes Care* 2008;31:2281 (Table 1).
* Инсулинов индекс: Holt, Brand Miller, Petocz. *Am J Clin Nutr* 1997;66:1264 и Bao et al. *Am J Clin Nutr* 2009;90:986.
  Скала: бял хляб = 100, порции от 1000 kJ. Стойностите не се изчисляват от ГИ; при липса на данни се показва „Няма данни“.
